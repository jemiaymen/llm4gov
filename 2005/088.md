**Article premier** : Sont créées au sein des directions régionales de l'enseignement relevant du Ministère de l'Éducation et de la Formation, les commissions administratives paritaires régionales suivantes :

**1ère commission** : Les professeurs agrégés principaux - les professeurs agrégés,

**2ème commission** : Les professeurs principaux hors classe de l'enseignement – les professeurs principaux hors classe du corps interdépartemental des enseignants de langue anglaise et d'informatique – Les professeurs principaux de l'enseignement secondaire – les professeurs principaux du corps interdépartemental des enseignants de langue anglaise et d'informatique,

**3ème commission** : Les professeurs hors classe de l'enseignement – les professeurs d'enseignement secondaire – les professeurs d'enseignement artistique – les professeurs d'enseignement secondaire technique – les professeurs du corps interdépartemental des enseignants de langue anglaise et d'informatique,

**4ème commission** : Les professeurs d'enseignement secondaire du 1er cycle – les professeurs d'enseignement artistique du 1er cycle – les professeurs d'enseignement technique du 1er cycle,

**5ème commission** : Les professeurs des écoles primaires,

**6ème commissions** : Les maîtres d'application principaux,

**7ème commission** : Les maîtres d'application - Les maîtres d'application de l'éducation manuelle et technique,

**8ème commission** : Les maîtres principaux,

**9ème commission** : Les maîtres – les maîtres de l'éducation manuelle et technique,

**10ème commission** : Les conseillers éducatifs principaux,

**11ème commission** : Les conseillers éducatifs,

**12ème commission** : Les conseillers éducatifs adjoints,

**13ème commission** : Les surveillants conseillers principaux,

**14ème commission** : Les surveillants conseillers,

**15ème commission** : Les surveillants principaux,

**16ème commission** : Les surveillants,

**17ème commission** : Les administrateurs – les ingénieurs des travaux,

**18ème commission** : Les attachés d'administration – les programmeurs – les techniciens – les gestionnaires adjoints de documents et d'archives,

**19ème commission** : Les secrétaires d'administration – les secrétaires dactylographes – les techniciens de laboratoire informatique – les adjoints techniques,

**20ème commission** : Les commis d'administration – les agents techniques – les dactylographes,

**21ème commission** : Les dactylographes adjoints – les agents d'accueil,

**22ème commission** : Les techniciens principaux hors classe de laboratoire – Les techniciens principaux de laboratoire,

**23ème commission** : Les techniciens de laboratoire,

**24ème commission** : Les préparateurs,

**25ème commission** : Les ouvriers de 1ère unité,

**26ème commission** : Les ouvriers de 2ème unité,

**27ème commission** : Les ouvriers de 3ème unité.
